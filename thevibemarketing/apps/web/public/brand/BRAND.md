# vibemarketer brand

## Canonical logo (official)

**Source file:** `logo-vibemarketer.png` (also `brand/logo-full.png`)

- **Mark:** Green gradient **V** + rising signal bars + growth arrow  
- **Wordmark:** `vibe` (green) + `marketer` (dark navy)  
- Metaphor: vibe + upward distribution / marketing growth  

This is the **primary brand**. Prefer it over older sparkline / V-Peak experiments.

## App wiring

- `BrandMark.tsx` → `/brand/mark-transparent.png`
- Nav / Footer wordmark: split **vibe** (accent) + **marketer** (ink)
- SEO Organization `logo` → `/brand/logo-full.png`
- Favicons / PWA → PNG + simplified SVG

## Colors (from logo)

- Growth greens: ~`#5a8a1a` → `#b8e04a`  
- Wordmark dark: navy/ink  
- Product UI still uses accent lime `#d4ff4a` for chrome; logo greens sit well next to it.

- Use old wordmark **thevibemarketing**
